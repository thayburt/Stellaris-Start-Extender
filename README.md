# Start Extender Usage
<p>Start Extender is a library which rewrites the vanilla initalization logic into a more extensible methodology using a variety of on actions while maintaining a identical behaviour.</p>
<p></p>

## General Logic
Start Extender begins by checking if Sol doesn't exist, running a chance check to create and populate the solar system if it doesn't exist. Next up Start Extender creates the shroud country if it doesn't already exist.
